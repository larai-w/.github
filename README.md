- [SECURITY.md](SECURITY.md) — 脆弱性の報告方法（security@veai.jp）
- [CONTRIBUTING.md](CONTRIBUTING.md) — 参加のしかた。コードを書かない参加、公開して
  はいけない情報の境界、健康・介護の文言のルール、AI 支援開発の扱い
- [PULL_REQUEST_TEMPLATE.md](PULL_REQUEST_TEMPLATE.md) — PR の型
